Cara Menjalankan Proyek:
1. Buka terminal atau Command Prompt dan arahkan ke dalam folder proyek.
2. Jalankan perintah: npx expo start
3. Pindai QR Code yang muncul di terminal menggunakan aplikasi Expo Go di smartphone.

Fitur yang Telah Diselesaikan:
- Menambahkan entri baru sehingga total terdapat 5 entri diary.
- Mengganti gambar remote dengan gambar lokal pada folder assets/moods.
- Menambahkan avatar pengguna pada bagian header menggunakan komponen Image.
- Membuat variasi warna border pada komponen DiaryCard berdasarkan jenis mood.
